# Sugar Free · Rohan & Riya

A tiny nightly check-in dashboard for quitting sugar together, starting 9 November 2026.

- **Together counter**: consecutive days where both of us stayed off added sugar
- **Nightly check-in** per person: 🌿 No sugar · 🍯 Healthy sugar (fruit, dates, honey: still counts) · 🍰 Slipped (resets the streak)
- **Notes** for anything worth remembering
- **Calendar** (left half Rohan, right half Riya). Tap a day to fix or backfill it.
- Milestones at 3, 7, 14, 21, 30, 50, 75, 100 days

Static `index.html` on GitHub Pages, data in Supabase (`sugar_log` table). To change the start date or milestones, edit the constants at the top of the `<script>`.
